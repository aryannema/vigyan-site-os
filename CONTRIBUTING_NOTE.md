# A note on history

All commits in this repository are authored by `aryannema`. Authorship was set before the first
push, deliberately: author and committer are written into each commit object, so pushing under a
different account changes only the *pusher*. Once pushed, the SHAs are public and changing them
means force-pushing over history that others may already have cloned.

If you fork this, decide your own authorship the same way — before your first push, not after.
