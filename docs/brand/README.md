# Brand pack

Placeholder identity for the template: `tokens.css` (the only source of colour,
type and radius values), `SKILL.md` (the rules agents follow) and `web/` (logo,
mark and icon files, copied byte-for-byte into `public/brand/` and `public/`).
Run the `site-bootstrap` skill to replace all of it with your own brand; then
`pnpm brand:check` confirms the Tailwind scales and public files match.
